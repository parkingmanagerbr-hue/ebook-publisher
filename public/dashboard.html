🤝 Sistema de Afiliados — Hotmart
50% comissão

O Hotmart possui um sistema nativo de afiliados. Ao ativar para cada e-book, qualquer pessoa pode se cadastrar como afiliado e receber 50% do valor líquido de cada venda que realizar. O produtor fica com os outros 50%. Com 71 e-books a R$4,99, isso significa que afiliados recebem ~R$2,00 por venda e você também.

1
Automação Puppeteer
Script navega em cada produto no Hotmart → aba Afiliados → ativa programa → define 50% comissão.
2
Link de Afiliado
Cada afiliado recebe um link único tipo hotmart.com/product/XXXXX?ref=AFILIADO para divulgar.
3
Hotmart Club
Acesse: Afiliados → Mercado de Afiliados. Aprove afiliados manualmente ou deixe aprovação automática.
4
Pagamentos
O Hotmart processa os repasses automaticamente no prazo estipulado (7–30 dias após venda confirmada).
🤖 Ativar Afiliados em Lote (Automático)

O agente vai navegar em cada produto publicado no Hotmart e configurar o programa de afiliados com 50% de comissão. Este processo leva ~2 min por produto (71 produtos ≈ 2h30m no total).

Cálculo do Repasse
Preço R$4,99 → Taxa Hotmart ~10% → Valor líquido ≈ R$4,50 → Afiliado recebe R$2,25 → Você recebe R$2,25
🔗
Link do Afiliado
Afiliado acessa Hotmart → Busca seus produtos → Pede para se afiliar → Recebe link único para divulgar.
🏦
Saque
Afiliados configuram conta bancária no próprio Hotmart. Saques após período de garantia (7 dias padrão).
